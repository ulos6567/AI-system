# Research: 차세대 편의점 표준 모델 — 통합·완성 계층

**Feature**: `003-next-gen-cvs-standard`
**Plan**: [plan.md](./plan.md) (Phase 0)
**Created**: 2026-06-10

Phase 0 의사결정 기록. 형식: Decision / Rationale / Alternatives.

---

## R1. 상품 코드 표준화 전략 (FR-001~003, SC-006)

- **Decision**: 본사 표준 상품 마스터 + 규칙 기반 매핑(완전일치 → 정규화 규칙). 규칙 미적중은 **추정하지 않고 `unmapped`/`review`로 명시**. 커버리지 = mapped/전체.
- **Rationale**: 점포별 코드 비정형성이 핵심 장벽. 추정 매핑은 오발주·폐기 리스크를 키우므로 미매핑 명시가 안전(Principle 7).
- **Alternatives**: ML 기반 자동 매핑(후속) — 1차 신뢰성·설명가능성 부족으로 제외. 점포별 자유 마스터 — 표준화 목적과 상충.

## R2. 오프라인 백업 결제 (FR-008~010, SC-005)

- **Decision**: 헬스체크 실패 감지 → 로컬 버퍼 적재(멱등키 부여) → 복구 감지 시 멱등 동기화. 이미 `synced`면 skip.
- **Rationale**: 가동률 99.99%는 장애 시 결제 연속성에서 결정. 멱등키로 이중결제(복구 경합)를 원천 차단.
- **Alternatives**: 장애 시 결제 차단 — 가동률·매출 손실로 제외. 큐 기반 외부 브로커 — 1차 과설계, 후속.

## R3. 외부 데이터 연동 (FR-011~013, SC-001/003)

- **Decision**: `external-data` 포트로 추상화, 1차 시뮬레이션 어댑터(시드 + 주기 잡). 중단 시 최신 유효값 또는 "데이터 없음" + 내부 데이터 폴백.
- **Rationale**: 실제 제공처 계약 전에도 예측 입력 결합·검증 가능(Principle 4/5). 포트 동일 형태라 실연동 교체에 명세 변경 불요.
- **Alternatives**: 즉시 실연동 — 계약·비용 미확정으로 제외.

## R4. 무대기 셀프 결제·대기시간 계측 (FR-005~006, SC-004)

- **Decision**: 셀프 결제 흐름에 시작/완료 타임스탬프 측정점 삽입, `wait_ms` 기록. 키오스크는 동일 스택의 모드 분리(고객 권한).
- **Rationale**: 10초 SLA 검증을 위해 흐름 내 직접 계측이 가장 정확. 이탈(abandoned)은 통계 분리.
- **Alternatives**: 외부 APM만으로 추정 — 거래 단위 정밀도 부족.

## R5. 거버넌스 게이트 (FR-007/016/017, SC-007)

- **Decision**: 데이터/결제 경로 진입 전 `consent/check` 게이트. 영상·행동은 비식별 집계만. 동의 철회 시 이후 수집 즉시 중단.
- **Rationale**: 개인정보 리스크가 주요 장벽. 게이트화로 모든 경로에 일관 강제(Principle 6).
- **Alternatives**: 사후 필터링 — 미수집 보장 불가로 제외.

## R6. KPI 단일 집계 (FR-014~015, SC-001~007)

- **Decision**: SC-001~007을 `kpi_snapshot` 단일 테이블로 집계, 대시보드는 단일 소스 노출.
- **Rationale**: 지표 정의 분산 방지·정합 보장. 폐기율/객단가는 001/002 결과의 측정 노출.
- **Alternatives**: 화면별 개별 질의 — 정의 드리프트 위험.

## R7. 예측 정확도 정의 (SC-003) — A1 해소

- **Decision**: 정확도 = **100 − MAPE**(품목·일 단위 평균 절대 백분율 오차) 기준, 목표 ≥90%.
- **Rationale**: 수요예측 도메인 표준 지표(001 forecast와 동일 계열). 명시로 검증 가능성 확보(Principle 3).
- **Alternatives**: 단순 적중률(±N%) — 직관적이나 오차 크기 미반영.
