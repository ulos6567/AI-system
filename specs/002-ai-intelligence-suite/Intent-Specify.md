# Intent - Specify

개요 / 미션
AI 기반 점포 운영 시스템으로, 편의점 고정비의 핵심인 인건비와 신선식품 폐기 손실을 최소화해 가맹점 영업이익률을 극대화한다.

빅데이터(과거 판매·유동 인구·연휴) 분석으로 발주 최적화 및 폐기 손실 최소화
단순 판매 공간을 넘어 자동화 결합 라이프스타일 플랫폼으로 확장


핵심 활동 (Key Activities)

데이터 수집·관리

내부: POS, 상품별 재고 순환 주기, 앱 구매 내역
외부: 날씨, 유동 인구(성별·연령), SNS 트렌드, 지역 행사·연휴
실시간: AI 카메라 기반 동선·상품 선택·체류 시간


AI 수요 예측·운영 최적화

 ai 추천 기반 발주 및 점주 제어 실시간 최적 가격·맞춤 프로모션, 진열·매장 구성 자동 최적화


디지털 운영 효율화

ESL 자동 가격 관리, ai 결제 시뮬레이터, 텍스트 기반 어시스턴트 챗봇으로 변경.


주요 유스케이스 (Use Case)
#Actor
시스템흐름1가맹점주AI 재고·수요 예측데이터 분석 → 수요 예측 → ai 추천 물류망 발주 예측 및 점주 제어로 → 모바일 모니터링2시스템(자동)·점주통합 프로모션·ESL조건 감지(유통기한·날씨) → 할인율 계산 → ESL 자동 반영 → 인근 앱 사용자 푸시3점주·시스템·고객AI 재고·수요 예측데이터 허브·센서 구축 → AI 모델·개인화 엔진 개발 → 직영점 테스트베드 검증 → 전사 확산·AX 교육

핵심 파트너 (Key Partners)

POS·결제 기업: 기존 POS(토스플레이스, 나이스정보통신 등) 데이터 자동 연동, 입력 부담 최소화 인터페이스
소상공인 연합회·지자체: 연합회 중심 인프라 보급으로 CAC 절감, '스마트 상점'·'디지털 전환' 보조금 연계
식자재 유통·물류 기업: AI 수요 예측 +  실시간 ai 추천 발주 및 점주 제어

핵심 이네이블러 (Key Enablers)

AI 분석: 자가학습형 수요 예측, 안면인식 보안
클라우드·스마트 인프라: 모바일 연동 클라우드 운영 시스템, 스마트시티 데이터(날씨·교통·유동 인구) 연동
지능형 자동화: AI 카메라 + 선반 중량 센서


핵심 데이터 (Key Data)

운영·수익성: 시간대별 폐기량·유통기한 패턴, 매장 유지비(임대료·인건비·공공요금), 피크타임 병목·작업 속도
입지·상권: 매장 앞 체류·진입률, 기상(강수·미세먼지)·지역 이벤트, 경쟁점 오픈·폐업 변동
고객 행동: 동선·매대별 체류 시간, 공간 환경(조도·온도·음악)–체류·객단가 상관관계, 비식별 단골 프로파일
물류·연계: 창고·선반 유휴 공간, 폐기 임박 상품–복지기관 나눔 매칭, '가는 길 배송' 루트


가치 제안 (Value Proposition)

점주: 심야 구인난 해소·인건비 절감, 정밀 수요 예측으로 악성 재고·폐기율 최소화
고객: 인구 밀집 지역에서도 무대기 즉시 결제, 24시간 안정적 재고

혜택 (Benefits)

신선식품 폐기 비용 방어·수익률 개선, 직원은 단순 결제 → 청결·서비스 집중
동선·체류 데이터 기반 최적 진열

비용 (Costs) / 수익 (Revenues)

비용: 하드웨어(무인 게이트·AI 카메라·스마트 매대), 클라우드 서버 구독료, 보안·개인정보 라이선스, 현장 유지보수 인건비
수익: 인건비·폐기율 절감 영업이익 상승, 맞춤 진열·타겟 마케팅 객단가 증가, B2B 솔루션 라이선스, 상권·소비 트렌드 데이터 판매


핵심 장벽 & 부정적 영향 (리스크)

데이터 비정형성: 점포별 상이한 메뉴명·상품 코드 → 표준화 어려움, AI 학습 효율 저하
소상공인 비용 부담: 초기 하드웨어·서버·구독료, 효과 입증 전 고정비 지출
사회적 영향: 파트타임 일자리 감소, 디지털 취약 계층 접근성 하락
시스템 의존성: 통신·서버 장애 시 운영 마비, 해킹·대규모 고객 데이터 유출 위험

비전 / 목표
데이터와 AI로 차세대 편의점 표준 모델을 구축한다. 편의점 비용의 두 축인 인건비와 신선식품 폐기 비용을 AI로 해결한다.

목표 1: 실시간 데이터 기반 스마트 발주로 신선식품 폐기율 50% 이상 절감
목표 2: AI 카메라·센서 기반 무인 운영으로 야간 인건비 절감

해결할 핵심 문제 (AS-IS)

감에 의존한 수동 발주 → 품절(기회 손실)과 폐기(재고 손실) 동시 발생
종이 가격표 교체·재고 점검 등 단순 반복 업무에 인력 소모
POS에 과거 매출·수량만 저장, 매장별 상품 코드 제각각 → 데이터 통합·실시간 외부 연동 불가
CCTV는 녹화·도난방지용일 뿐 고객 행동 데이터는 미활용

개선 방향 (Gap)

데이터: 흩어진 상품 코드 표준화 → 내부(POS) + 외부(날씨·상권) + 실시간(영상)을 모으는 통합 데이터 허브
기술: 녹화용 CCTV·종이 가격표 → AI 카메라, 무게 센서, 전자가격표시기(ESL)로 구성된 실시간 센서 네트워크
프로세스: 사후 대응 → AI가 수요를 예측해 자동 발주·알림을 실행하는 사전 예측 방식

반정형/비정형: 날씨 API, 공공 상권 데이터, 스마트시티 유동 인구, 지역 행사 일정
